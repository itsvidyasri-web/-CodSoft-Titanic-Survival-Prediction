# Titanic Survival Prediction Using Machine Learning

## Project Overview
This project predicts whether a passenger would survive the Titanic disaster using Machine Learning.

The model analyzes passenger information such as age, gender, passenger class, family members, ticket fare, and boarding port to predict survival.

## Project Objectives
- Analyze the Titanic passenger dataset.
- Perform data cleaning and preprocessing.
- Train a Machine Learning classification model.
- Evaluate model performance.
- Build an interactive web application using Streamlit.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib
- GitHub

## Dataset
The project uses the Titanic dataset containing 891 passenger records and 12 original columns.

## Model Performance
- Model Accuracy: **81.01%**
- Training Data: 712 records
- Testing Data: 179 records

## Features
- Predict passenger survival.
- Interactive user interface.
- Passenger details input.
- Real-time prediction results.
- Machine Learning model integration.

## How to Run the Project

1. Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Install the required libraries:

```bash
pip install -r requirements.txt
```

3. Run the Streamlit application:

```bash
streamlit run app.py
```

4. Open the local URL displayed in your terminal.
